1 Base Documental Estricta

El asistente responde únicamente con base en los manuales PDF cargados por el perfil Administrativo. Nunca inventa plazos ni requisitos.

2 Carta Oficial vs. Soporte

En modo Redactar PQRS se separa la Carta Oficial (lista para copiar o descargar en Word) del Soporte Interno para el funcionario.

3 Protección Habeas Data

Antes de analizar, el sistema cifra automáticamente nombres, cédulas, teléfonos y correos (Ley 1581 de 2012). Haz clic en el escudo verde para auditar.

4 Inclusión y Voz

Usa Dictar para hablar tu consulta, Escuchar para oír las respuestas y el botón azul inferior derecho para activar alto contraste o lectura para dislexia.
